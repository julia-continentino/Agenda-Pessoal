# Agenda Pessoal

Agenda pessoal de projetos com timesheet automático. Abre em qualquer navegador (computador ou celular).

Link: https://julia-continentino.github.io/Agenda-Pessoal/

- **Agenda:** o que fazer no dia. "Começar" ao iniciar, quadradinho ao terminar; os horários são registrados sozinhos.
- **Timesheet:** totais por dia, semana, mês e projeto. Baixa CSV ou copia para o Excel.
- **Projetos:** escopo (PPA, Impairment, Marcação de Cota, Valuation, Business Plan), datas, etapas LEAP, e-mails e anotações.

Os dados ficam no Firebase (projeto próprio da agenda), protegidos por login com e-mail e senha e pelas regras em `firestore.rules`. Este repositório guarda só o código da página, nenhum dado.
